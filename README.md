# Tanish Khurana — Data Analyst Portfolio

Complete static HTML/CSS/JavaScript portfolio, ready for GitHub Pages.

## Preview
Open `index.html` in a browser. All seven project illustrations are local SVGs.

## Publish
Upload the **contents** of this folder to your GitHub repository root, including the `assets` folder. In Settings → Pages, choose `Deploy from a branch`, `main`, `/ (root)`.
